# Proposed rules: a run of cabinets along one wall

**Status: proposal for Max's approval. Nothing here is built yet.** Once approved, these become section R of [RULES.md](RULES.md) and the engine is changed to match. This is stage 2 of the kitchen work; stage 1 (one cabinet at a time) is built.

## The idea

Today each project is one cabinet. A kitchen wall is several cabinets side by side, usually with an appliance or two between them.

With a run, she tells the app how long the wall is and what goes along it, left to right. The app sizes every cabinet, and produces one shopping list, one set of cutting diagrams and one build, cabinet by cabinet.

Each cabinet in the run is still built by the rules already approved (sections B to K). This proposal covers only what is new when cabinets sit together.

## R1. What she enters

- **The length of the run**: wall to wall, or wall to open end. One number.
- **What goes along it**, left to right, chosen from pictures: base cabinet, drawer base, sink base, or a space for an appliance.
- **Depth and height** are entered once and shared by every base cabinet in the run, starting at 24" and 31" (rule K1).
- **Which ends touch a wall**, as now.

That is all. She does not type a width for each cabinet.

## R2. Widths: the app shares the run out

This works the same way as openings in a face frame (rule L3).

- An appliance space has a width to start with: 30" for a range, 24" for a dishwasher, 36" for a fridge. These are defaults she can change, and they are marked "check before you cut", because the real appliance decides.
- A sink base starts at 36".
- Every other cabinet shares what is left equally. Shares are rounded down to the tape mark and the leftover goes to the last one, so the widths always add up to the run exactly (rule U4).
- She can fix any cabinet's width. The others then share the rest.
- If everything is fixed and it does not add up, that is an error, shown as a picture of the pieces against the wall with the gap or overlap marked, like the opening check (rule L1).

## R3. Each cabinet is its own box, screwed to its neighbours

Every cabinet is built complete, with its own face frame, then the cabinets are clamped and screwed together through the frame pieces where they meet.

- Where two cabinets meet there are two vertical frame pieces side by side.
- The frame overhang (rule F1) applies only at a wall end of the run. Where cabinets meet, frame and box are flush.
- A side that meets another cabinet is never seen, so its pocket holes can go on the outside face (rule J2).

Why separate boxes: each one is light enough to lift, is finished before the next is started, and a mistake costs one cabinet. The alternative is one long face frame across several boxes, which looks cleaner but must be built in place and is hard to get square.

## R4. One platform for each stretch

- One 2x4 platform runs under each unbroken stretch of base cabinets (rules P1 to P5), not one per cabinet.
- An appliance space has no platform. The stretch ends there and the next one starts on the other side.
- A stretch longer than a 2x4 (8 ft) is built in sections, with the joint under a place where two cabinets meet.
- The toe kick runs the length of each stretch, with returns on ends that can be seen, including next to a range or fridge.

## R5. Numbering

Cabinets are numbered left to right: C01, C02, C03. Appliance spaces are not numbered. Every part carries its cabinet's number: C01-01, C01-02. Platform and toe kick parts belong to the run and are numbered R-01, R-02.

## R6. One shopping list, shared sheets

- One shopping list for the whole run.
- Cutting diagrams place parts from different cabinets on the same sheet or board (rules C1 to C7), so less is wasted than building each cabinet alone. Each piece shows its cabinet and part number.
- Ticks for bought and cut work across the whole run.

## R7. Building it

- The Build screen goes one cabinet at a time: all of C01's steps, then C02's. She can jump to any cabinet.
- After the last cabinet there is a short set of steps for the run: place the platforms, set the cabinets on them from one end, clamp and screw each to its neighbour, screw to the wall, fix the toe kicks.
- Two cabinets that are the same size are still listed separately, so each has its own ticks.

## R8. Checks

- The widths must add up to the run (R2).
- A cabinet that comes out narrower than 9" or wider than 48" is an error with a suggested fix (add or remove a cabinet).
- Every check that applies to a single cabinet still applies to each one.

## Not in this stage

- **Corners.** A run is one straight wall.
- **Upper cabinets in the same project.** An upper is still planned on its own, as in stage 1. Lining uppers up over a base run comes with the room planner.
- **Countertops**, which are made by others.
- **Filler strips.** With shared widths the cabinets always fill the run, so none are needed yet.

## What changes in the app

- "A whole kitchen" on the start screen becomes "Kitchen run" and can be started.
- A new Run screen: the run length, and the row of cabinets and appliance spaces as pictures she can add to, remove from and reorder, with a to-scale drawing of the whole run.
- Parts, Cutting, Shop and Build cover the whole run, with the cabinet number on everything.
