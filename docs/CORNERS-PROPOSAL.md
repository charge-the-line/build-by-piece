# Proposed rules: a corner (two walls)

**Status: proposal for Max's approval. Nothing here is built yet.** Once approved, these become section N of [RULES.md](RULES.md) and the engine is changed to match.

## The idea

Today a run is one straight wall. Most kitchens turn a corner.

With this change a project can have two walls that meet. She gives the length of each wall and what goes along it, exactly as now. The app works out the corner: which cabinet goes into it, where the second wall's cabinets start, and what covers the gap.

Each wall is still a run built by the rules already approved (sections R and W). This proposal covers only what happens where the two runs meet.

## The kind of corner

There are three common ways to build a corner. I propose the first.

| | What it is | For a beginner |
|---|---|---|
| **Blind corner** (proposed) | One wall's last cabinet runs all the way into the corner. The other wall's cabinets start in front of it. Part of the corner cabinet is hidden, and reached through its door. | Every box is still a plain rectangle. Nothing new to learn. |
| Empty corner | Both walls stop short and the corner is boxed off. | Easiest, but wastes the corner. |
| Diagonal or L-shaped cabinet | One five- or six-sided box fills the corner. | Angled cuts and an odd-shaped frame. Hard. |

## N1. What she enters

- **The length of each wall**, measured from the corner to the far end.
- **What goes along each wall**, as now (rule R1), listed from the corner outwards.
- **Which side the second wall is on**: it turns towards you at the left end or the right end of the first wall. A choice with a default (right).
- **What is at each far end**: a wall or open, as now.

Depth, height and all the other choices are shared by both walls. She does not enter anything about the corner itself.

## N2. Which wall goes into the corner

The first wall's cabinets run right into the corner. The second wall's cabinets start in front of them. She can swap this; it is a choice with a default.

## N3. The corner cabinet

The cabinet at the corner end of the first wall becomes a **corner base cabinet**. It is an ordinary base cabinet (rule K2) except for its front:

- **Hidden part** = the depth of the second wall's cabinets + the gap strip (N4). With the defaults that is 24" + 3" = 27". This part of the front has no opening. It is closed with a plain plywood panel behind the frame.
- **The rest** is one door opening, sized by the usual rules (K4), with a shelf behind it.
- It starts at 45" wide, a default she can change. It must be wide enough for the hidden part and a door of at least 9"; if not, that is an error with the fix.
- Its corner end counts as a wall end (frame overhang, rule F1).

The app puts a corner cabinet there itself. If she had a sink base or a drawer base listed first on that wall, the app adds the corner cabinet before it and says so; she is not asked.

## N4. The gap strip

Doors and drawers need room to open past the handles on the other wall. So:

- The second wall's first cabinet starts 3" out from the front of the first wall's cabinets. The 3" is a default she can change.
- The gap is covered by an oak **gap strip** the height of the frame, screwed to the second wall's first cabinet through its end frame piece. The trade term is "filler strip" (in the glossary).
- The same 3" is why the corner cabinet's hidden part is 3" wider than the cabinets in front of it (N3).

## N5. The second wall

Length for cabinets on the second wall = wall length − depth of the first wall's cabinets − gap strip. With the defaults and a 96" wall that is 96" − 24" − 3" = 69".

That length is shared out by the usual rule (R2). The corner end of this run is treated as joined (no overhang, pocket holes outside). An appliance space cannot be first at the corner on either wall; that is an error with the fix (put a cabinet between).

## N6. Platforms and toe kick

Each wall has its own platforms (rule R4). The second wall's first platform and its toe kick run on across the gap to meet the first wall's toe kick, so the corner looks continuous at the floor.

## N7. Upper cabinets in the corner

The same idea, one size smaller, because uppers are 12" deep:

- The first wall's corner upper runs into the corner. Its hidden part = upper depth + gap strip = 12" + 3" = 15", closed the same way.
- The second wall's uppers start 15" from the corner, with their own gap strip.
- So the second wall's first upper is wider than the cabinet under it by the difference in depths (24" − 12" = 12"). This is the one place where an upper is not the same width as what is underneath (rule W2).
- The corner upper is proposed by default (W1) and can be switched to "Nothing" like any other.

## N8. Numbers, lists and building order

- Cabinets are numbered along the first wall, then the second: C01, C02, ... and U01, U02, ... as now. Gap strips are run parts (R-01, ...).
- One shopping list, one set of cutting diagrams, one tool list for both walls (rules R6, W7).
- Order: build every base cabinet, then every upper. Set the first wall's base cabinets starting **at the corner**, then the second wall's starting at the corner, with the gap strip. Then hang the uppers the same way. Then drawers, doors and handles.
- The corner cabinet is the heaviest box in the kitchen. The app says it is a two-person lift.

## What changes in the app

- The projects panel offers "Kitchen with a corner" beside "Kitchen run".
- The Run screen shows a simple picture from above with both walls, then each wall from the front. Each wall has its own list.
- Parts, Cutting, Shop and Build cover both walls. Step pictures for the second wall are drawn facing that wall.

## Not in this stage

- A third wall (a U-shape) or an island.
- A turntable or pull-out inside the corner cabinet.
- Diagonal and L-shaped corner cabinets.
- Windows, doors and plumbing positions. Those come with the room.
- The countertop, which is still by others.
